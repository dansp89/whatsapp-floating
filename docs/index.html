    WhatsApp Floating — Live Demo

    This page loads the library straight from jsDelivr (npm), the same way you would in production. The floating button is rendered by the library itself — no extra HTML required.

    Basics

    Message, fallback number and default images.

    Digits only, with country code (e.g. 5511999999999)
    Corner the button is anchored to.
    Enable any combination of sides. Values accept px or any CSS length ("10%", "2rem").
    Supports {{city}}, {{state}}, {{country}}, {{ip}}, {{ip_base64}}— type {{for suggestions.
    Folder hosting whatsapp-desktop.png / whatsapp-mobile.png — the library appends those filenames itself.
    Full URL to each image file — used exactly as entered, nothing appended.

    Location rules

    Route to a different number based on the visitor's country, state or city. Evaluated City → State → Country → Fallback.

    No location rules yet — every visitor gets the fallback number.

    Path rules

    Override the number and/or image based on the current URL path (e.g. a campaign landing page). Checked before location rules.

    No path rules yet.
